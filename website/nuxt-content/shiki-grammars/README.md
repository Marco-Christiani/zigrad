# Shiki Grammars

This directory contains custom TextMate grammars loaded by [`app/mdc.config.ts`](./app/mdc.config.ts).

Current grammars:

- `mlir-grammar.json`: upstream LLVM VS Code MLIR grammar
- `pdll-grammar.json`: upstream LLVM VS Code PDLL grammar
- `tablegen-grammar.json`: upstream LLVM VS Code TableGen grammar
- `zxpr-grammar.json`: our ZXPR grammar
